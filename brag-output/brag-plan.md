# brag-plan — Iheb Hamdi portfolio

**What it is:** Iheb Hamdi's portfolio, a Full-Stack Engineer in Barcelona. It isn't a static CV: the site shows his live GitHub year as a 3D skyline, has an AI assistant that answers questions from his CV, and has a contact form that actually sends.

**Who it's for:** recruiters and clients deciding whether to talk to him. They can ask the CV questions, check that he really ships, and message him in one step.

**Angle:** a real visit, recorded in the real site. The video drives the actual React app (the real components, CSS, Geist font and framer-motion entrances) with a simulated cursor: scroll, hover, click, type.

**Hook (0–2s):** "Iheb / Hamdi" rises out of its mask while the portrait wipes up. This is the site's own entrance animation.

**Highlights**
1. GitHub history: the flat contribution heat map folds up into a 3D skyline (real data: 915 contributions in the last year). The video hovers the busiest day and toggles 2D/3D.
2. AI assistant: the floating launcher opens the chat, a suggested question is clicked, and the answer streams in. The answer is quoted from the CV (the live API is offline during capture, so the stream is mocked locally).
3. Contact: the form gets typed into and sent, then shows the real "Message sent." state.

**Punchline / outro:** a white end card reading "Iheb Hamdi", then "Full-Stack Engineer · Barcelona", then the site URL.

**Tone:** polished. Calm and clean, with long, readable holds and soft camera push-ins. Music is a gentle D-major electric-piano and pad loop with no hard drums.

**Identity:** a white page with near-black (#0a0a0a / oklch 0.145) Geist Variable type, GitHub greens on the skyline, and indigo (oklch 0.585 0.233 277) for the chatbot only.

**Format:** 1920×1080, 30fps, 30s (as the user asked).
